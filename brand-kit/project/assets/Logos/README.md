# Logos

Our logo files. Use SVG for web and print. Use PNG for Word and PowerPoint.

- `fjbs-logo`: the full logo. Use this most.
- `fjbs-wordmark`: words only.
- `fjbs-mark`: globe only.

Colours: `primary` for white, `on-dark` for dark, `on-blue` for blue, `mono-ink` for all dark, `mono-white` for all white.
